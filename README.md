# Cathy Releases

This repository distributes prebuilt Cathy binaries. Cathy is a terminal-based
coding agent with an interactive TUI, persistent threads, native tools, MCP
integration, reusable skills, and support for several LLM providers.

> **Release staging:** this repository remains private while the first alpha,
> documentation, and artifacts are reviewed. It should be made public only
> after explicit approval.

The source repository is private. This repository contains distribution
documentation and generated release artifacts, not Cathy source code.

## Download

Open [Releases](https://github.com/charles-chenzz/cathy-release/releases) and
download the archive matching your system:

| Operating system | Architectures | Archive |
|---|---|---|
| Linux | amd64, arm64 | `cathy_VERSION_linux_ARCH.tar.gz` |
| macOS | amd64, arm64 | `cathy_VERSION_darwin_ARCH.tar.gz` |
| Windows | amd64, arm64 | `cathy_VERSION_windows_ARCH.zip` |

Linux is supported. macOS is supported but its binaries are not yet signed or
notarized. Windows is experimental and its binaries are not yet signed.

## Verify

Download `checksums.txt` from the same release before extracting the archive.
On Linux:

```bash
archive=cathy_0.1.0-alpha.1_linux_amd64.tar.gz
grep " ${archive}$" checksums.txt | sha256sum -c -
```

On macOS:

```bash
archive=cathy_0.1.0-alpha.1_darwin_arm64.tar.gz
grep " ${archive}$" checksums.txt | shasum -a 256 -c -
```

On Windows PowerShell, compare the output of the following command with the
matching line in `checksums.txt`:

```powershell
Get-FileHash .\cathy_0.1.0-alpha.1_windows_amd64.zip -Algorithm SHA256
```

Each archive also has an SBOM asset generated by Syft.

## Install

Linux or macOS:

```bash
tar -xzf cathy_VERSION_OS_ARCH.tar.gz
sudo install -m 0755 cathy /usr/local/bin/cathy
cathy --version
```

Windows: extract `cathy.exe` from the zip archive, move it to a directory on
your user `PATH`, and run `cathy --version` in a new terminal.

On macOS, Gatekeeper may warn because the binary is not notarized. Verify the
checksum before deciding whether to allow the binary in system settings.

## Start

Run Cathy from the project directory it should work in:

```bash
cd /path/to/project
cathy
```

The first-run TUI configures an API-key or OAuth-backed model. User
configuration, credentials, local traces, and saved threads are stored under
`~/.cathy`.

Cathy asks for approval before every local Bash command, but approved commands
run as your user without an isolation sandbox. Review every command before
approval and use narrowly scoped provider and MCP credentials.

## Uninstall

Remove the installed binary. To remove all local Cathy configuration, login
data, saved threads, and traces, also remove `~/.cathy`:

```bash
rm -f /usr/local/bin/cathy
rm -rf ~/.cathy
```

Back up any saved threads you want to keep before removing `~/.cathy`.
